# Журнал проекта

## Контекст

Проект: GuitarTabsTranscription, новая архитектурная ветка распознавания гитарных
табулатур по аудио. Используются прежние данные SynthTab; история экспериментов
TabCNN находится в отдельном PP-VKL-GuitarTabs. Следующие архитектуры планируются
отдельно; итерация 0 предоставляет только инфраструктуру PyTorch.

Данные и артефакты хранятся вне Git. Формат: шесть струн, лады 0–24,
класс тишины 25, шаг 16 мс, порядок струн от шестой к первой.
